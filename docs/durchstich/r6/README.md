# Abschlussdurchstich (R6) — Skripte und Bilder

Die Skripte sind die, mit denen der Lauf in `docs/final-report.md` (Abschnitt „Durchstich vom frischen Klon") gemacht wurde, mit zwei Änderungen: Zugangsdaten kommen aus `TN_CLIENT_ID`/`TN_CLIENT_SECRET` statt aus dem Quelltext (`api_check.py` und `cam_probe.py` brauchen zusätzlich einen Zugang mit Scope `bulk-import`, wie im Skript kommentiert bzw. im Bericht beschrieben), und die Pfade sind die der Windows-Maschine, auf der sie liefen. Sie sind Belege, kein Werkzeug des Projekts.
`synthetic-boundaries.geojson` sind drei von Hand gezeichnete Rechtecke (DE/CH/FR), **keine** echten Landesgrenzen.
